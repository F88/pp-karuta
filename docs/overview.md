# PPK26

## 概要

[ProtoPedia](https://protopedia.net/)に登録された作品を札として遊ぶ、かるたです。

## 機能

- **ルールはかるた**: 読み札の読み上げ、取り札の選択、正誤判定、スコア計算という一連のかるたゲーム進行
- **1人から4人でプレイ可能**: 最大4人まで一緒に遊べる(競える)
- **多彩なデッキ**: デッキレシピにより様々なテーマの札セットを選択可能
    - 全作品、かるた、PROMIDASなどのタグ別デッキ
    - 干支 (十二支) デッキ
    - お正月、節分、七夕、ハロウィン、クリスマスなどの歳時・イベントデッキ
    - 年別デッキ
- **タッチ/キーボード対応**: デバイスに応じた2種類の入力方式、スマートフォン/タブレット/PCでプレイ可能
- **ゲーム結果の表示**: 各プレイヤーの獲得枚数をランキング表示
- **レスポンシブデザイン**: スマートフォン/タブレット/PCの3画面サイズに対応

## Protopedia API トークン

PPK26で遊ぶためにはProtoPedia API v2のトークンが必要です。

参考: [ProtoPedia API v2](https://protopediav2.docs.apiary.io/)
